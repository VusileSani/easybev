# GoodKota v5.0 — Platform Governance

This release adds a company-governance layer above the existing GoodKota operating roles.

Key changes:
- universal actor dropdown: Customer, Merchant, Driver, Delivery Ops, GoodKota Admin, GoodKota Owner
- distinct Owner and Admin workspaces
- protected Owner-only company controls
- at-least-one-active-Owner invariant
- Owner-managed platform staff authority
- privileged and operational audit histories
- support case queue and merchant-originated support requests
- platform announcements targeted by actor group
- merchant commercial/subscription status
- reason-coded merchant and quality interventions
- maintenance mode that actually pauses normal actor access
- ordering/payment/delivery/onboarding controls wired into operating screens
- real merchant street-address capture with coordinate resolution/manual coordinate fallback
- customer area search can resolve South African locations beyond the original seeded area list
- stable actor navigation with no page scaling/zoom transitions
